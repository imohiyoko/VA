# 参考 3: 依存関係

> 実際の実行は `scripts/va.py`（ツール実行）と `checklists/` が担う。ここは人が読むための背景説明。

1. ロックファイルの有無を確認（無いこと自体を低重大度で記録）
2. `osv-scanner --recursive .` を実行し、既知脆弱性を取得
3. 各脆弱性について **実際にその機能を使っているか（到達可能性）** をコードから確認する
   - 使っていない: 重大度を下げ、`reachability: unreachable` を付ける
   - 判断できない: `reachability: unknown`
4. メンテナンス停止・タイポスクワッティングが疑われるパッケージ名、
   Git URL やローカルパス指定の依存、バージョン未固定（`*`, `latest`）を記録する
5. postinstall 等のインストールスクリプトを持つ依存は名前だけ記録する（実行しない）
