# モデルプロファイル

AI モデルごとの傾向と、それを打ち消すための補正をまとめる。
診断の実行時、`meta.json` の `model` と同じ名前のファイル（例: `claude-opus-5-5.md`）があれば、その中の `- [summarize|review|triage|all] ...` の行が該当タスクのプロンプトに自動で追加される。

- ファイル名はモデル ID そのもの（API のモデル文字列）
- 内容は**観測に基づくものだけ**を書く。推測や評判は書かない
- 新しいモデルを使い始めたら `_template.md` をコピーして空のまま作ってよい。
  観測は retrospective が `type: model` の上流候補として提案し、PR で追記される
- 補正はモデルの世代が変わると逆効果になりうるので、各項目に「観測した VA バージョンと時期」を残す
